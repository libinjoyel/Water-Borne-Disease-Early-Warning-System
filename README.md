# Water-Borne-Disease-Early-Warning-System

## AI Assistant Setup

1. Create `backend/.env` from `backend/.env.example` and set `GOOGLE_API_KEY`.
2. Optionally set `GOOGLE_MODEL` if you want a different Gemini model.
3. Create `frontend/.env` from `frontend/.env.example` if your backend is not running on `http://localhost:5000`.
4. Start the backend from `backend/` and the frontend from `frontend/`.

The AI assistant is available in the main navigation as `AI Assistant`.
